# W-140: save the baked island, load it instead of rebuilding (world lane)

Tree: Punchy-world. Branch `world/island-cache`, new from origin/main.
Read first: COORDINATION.md (rules 15-22), IslandV2.cs (IslandV2System, the island-ready frame), TerrainAuthoring.cs
(BuildSource, BuildPlaces and its stage order), TerrainSource.cs (every blob it holds), WorldSync.cs (what clients get),
and the bake-stage table in REPORTS-profiler.md ("Ranked bake stages").

**Why (Zach 11-11):** there will be one designed island (#260), and the launch bake (about 14 s island-ready frame on v3)
is a bottleneck for the profiler and for every playtest. "I think sooner is better." Layouts still change every week, so
this is a cache of the generator's output, not a frozen world: it is rebuilt by itself whenever the generator or its
settings change. It is also the first step of #260's world file.
