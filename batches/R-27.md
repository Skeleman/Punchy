returns. Derivatives after divergent returns are undefined: in a quad where some pixels returned, the normal (and so
the shadow test bias) can be garbage on some GPUs. Shows as speckle or edge shimmer in cached flora shadows, which is
one of Zach's recurring shadow complaints. Serves shared foundations (3).
