# M-05 (DRAFT, awaiting Zach): Model Lab, load any model and tune proportions and key frames

Status: draft; not assigned. Zach (11-10): "an interface for the creatures, colossi, houses, ruins, etc. that allow me to load one up
and adjust the model proportions and key frames."
Lanes: animal (creatures, colossi), world (houses, kit, ruins); one shared viewer.

Today everything is built in code: proportions are constants inside each builder and gaits are procedural curves, so a change means
a code edit and a rebuild.

## Row 1: inventory (no code)
- For each family (creatures, colossi, kit houses, ruins, landmarks), list how it's built, which numbers set its proportions, and
  what "key frames" means for it (gait phase curves, the colossus walk cycle, sway). Estimate per family.

## Row 2: parameters as data
- Move the main proportion numbers per kind into one tunables file (JSON or a ScriptableObject) that the builders read.
  Defaults equal today's constants, so nothing changes and the pins hold until Zach saves an edit.

## Row 3: the Lab
- A viewer that loads any kind by name onto a turntable with a grid and a size reference (human).
- Sliders for its proportions; the model rebuilds live.
- A timeline: play, pause and scrub the walk/run/idle cycle; edit key poses or curve points; loop at any speed.
- Save writes the tunables file (a git diff Zach can review); Reset goes back to defaults.

## Row 4: more families
- Houses and ruins next (wall height, roof pitch, footprint, wear), then landmarks.
