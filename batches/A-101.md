# A-101: anyone climbs marked walls (animal lane, #267)

Tree: first free fauna tree after A-100. Branch `fauna/route-climbing`, new from origin/main. Pairs with W-144 (world lane:
climb routes in caves, and the "is this climbable" query). Read first: COORDINATION.md (rules 15-23), PlayerMovementSystem
(the #33 wall climb: OnWall, latch, top-out, stick relative to the wall), the `-place wall` test.

**Why (Zach 11-11, #267):** "Perhaps caves with vertical sections can have climbable walls?"

**Unified climbing (Zach 11-12):** "it is important to try to unify the climbing system as much as possible... adapted into a
sort of 'climbability' parameter of a vertical section and be evaluated on a character-by-character skill. For animals, this
is fixed. For humanoids, this will be derived from some stats, but we can give it a single variable for now."
One scale for every climb in the game (trees, walls, cave routes, ladders, later colossi). Each climbable vertical section
carries a **Climbability grade**, hardest first:
5 smooth wall, 4 craggy wall (rough rock, cracks, handholds), 3 tree, 2 assisted (vines, webs, trellis, roots, rope),
1 ladder. Each character carries a **ClimbSkill** (0-5): it may climb a section when ClimbSkill >= grade, faster the bigger
the margin. Animals: fixed per species, replacing today's ClimbAbility (None -> 0, Trees -> 3, AnySurface -> 5; tune per
species, e.g. a spider 5, a bear 3, a goat-like climber 4). Humanoids: one variable for now (default 2: ladders and assisted;
later from stats). Ladders only in structures and villages (docks, mines, some houses' roofs). A way out that a player must
take (a cave drop with no other exit) is grade 2 or easier; grade 3-5 routes are optional shortcuts for good climbers.
Network: grade is seed-derived (bake records); ClimbSkill is the character's own state (synced like species).
